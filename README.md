# team-analyzer-privacy

Public repository hosting the privacy policy for the Team Analyzer browser extension for [Pokémon Showdown](https://play.pokemonshowdown.com/).

The policy is rendered at <https://surfnwob.github.io/team-analyzer-privacy/> via GitHub Pages.

## Reporting issues

If something in the policy is unclear, missing, or wrong, please [open an issue](https://github.com/surfnWOB/team-analyzer-privacy/issues) or email surfnWOB@gmail.com.
